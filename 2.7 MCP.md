**Vad är MCP?**
MCP – Model Context Protocol – är en öppen standard för att koppla verktyg, databaser och tjänster till en AI.

Ett vanligt API är svårt för en AI att använda: den måste hitta dokumentationen, förstå vad som är möjligt och hur man loggar in. En MCP-server löser det genom att själv berätta vad den kan. När Claude Code ansluter frågar den servern "vad kan du?" och får tillbaka en lista med verktyg. De exponeras som tools för modellen – samma sorts verktyg som Read och Bash.

**Lokal eller remote**
- **Lokal (stdio)** – servern är en process som körs på din dator. T.ex. en Git-MCP mot ett specifikt repo.
- **Remote (HTTP)** – servern ligger på nätet, t.ex. GitHub, Figma eller Notion. Oftast med inloggning via OAuth.

**Var de konfigureras**

| Scope | Gäller | Delas med teamet | Ligger i |
|---|---|---|---|
| Lokal (standard) | Bara det här projektet | Nej | `~/.claude.json` |
| Projekt | Det här projektet | Ja, via git | `.mcp.json` |
| Användare | Alla dina projekt | Nej | `~/.claude.json` |

En projekt-MCP från `.mcp.json` måste godkännas innan den används – ett klonat repo kan inte koppla in servrar åt dig.

**Kontexten**
Verktygen laddas vid behov (tool search) – de ligger och väntar utanför kontexten tills de behövs. I min egen `/context` väntade 142 MCP-verktyg (56,7k tokens) utanför kontexten (se 2.2). Men varje verktyg som används tar plats, och svaren kan bli stora – Claude Code varnar över 10 000 tokens.

**Är MCP på väg ut?**
Det pratas mycket om att MCP är "dött" och att CLI-verktyg + skills tar över. Det stämmer delvis:
- **CLI + skill** är ofta billigare och lika bra för det modellen redan kan, som `git`, `gh` eller `npm`. Arize jämförde och fick samma träffsäkerhet – men MCP kostade upp till sex gånger mer på de svåraste uppgifterna, eftersom agenten behövde fler och pratigare anrop.
- **MCP** passar för tjänster med inloggning (OAuth), behörigheter per verktyg, och där organisationen vill styra vad som är tillåtet.

Svaret är inte antingen eller: CLI när du bygger lokalt, MCP för styrd åtkomst till tjänster, och skills ovanpå båda för att tala om *hur* jobbet ska göras.

**Säkerhet** – MCP-servern jobbar med din inloggning. Lita på servern innan du kopplar in den: servrar som hämtar innehåll utifrån kan ge prompt injection (se 4.3 och 4.5).
