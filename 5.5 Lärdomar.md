
Varje ny chatsession blir som en ny teammate, målet är att få dom alla att följa dina uppsatta regler för projektet. 

T.ex. 
Någon agent freebasar och skapar en history logg i rules. 
Hur hittar du det? När hittar du det? 

Ha koll på varje ändring/commit eller PR och gå igenom noggrant
Kolla av skills och rules med jämna mellanrum, som de innehåller onödig text

Lärdomar. Be AIn förklara om det är något du inte förstår, jag har ett command (vi måste lägga till commands) som jag kan använda. Då förklarar den på en enkel nivå och jag kan be den att gå djupare om jag vill. Repetition är kunskapens moder, saker jag upptäcker händer flera gånger lär jag mig efter ett tag även om jag inte förstår det fullt ut de första gångerna. Här är det ju också bra att dubbelkolla med mer erfarna kollegor. 

Om ditt projekt inte är enhetligt kan det gå snabbt utför. AIn kan läsa dina skills och regler, men den kan också hämta inspiration ifrån hur ditt projekt ser ut. Har du otur hämtar den infon ifrån den delen av projektet som kanske har en del kvar att önska och då växer det problemet.

Agenter är supereffektiva. Det betyder att vad som hade funkat för en normal människa i form av gratis begränsningar på google, github etc konton lätt kan överskridas. Se till att se över det INNAN det överskrivs.

Jag har 250 rader / fil som max för det var vad rekommendationerna sa för en månad sedan. Saker ändras hela tiden och det gäller att hänga med. Man kan även dela upp en skill i flera filer inuti filen tillsammans med scripts som den kan använda vilket gör det mer till en egen tool.


Exempel
 
Github / minut
 Githubs privata konton t.ex. har bara 2000 minuter av github actions per månad. Det går åt på en helg med lite effektivt AI arbete om du inte begränsar vad som körs etc.
 
 Github rate limit
 Mina genter körde gh project item-list vilket plockade hem hela boarden med items varje call och snabbt körde in i rate limiten. Agenten hade en egen solution, att den bara skulle hämta varje issue med dess id men den behövde veta vilka som skulle göras innan den viste dess id så då fick jag föreslå att den skulle sätta ett filter på vilken board (milestone samt status) den skulle läsa. 
 
 Den skrev regler med massa metadata som var helt onödig och jag trodde att det var säkert att be den skriva sina egna rules...
