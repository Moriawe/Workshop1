
I `~/.claude` (på Windows `%USERPROFILE%\.claude`) skrivs massor av filer medan du jobbar. Det ser ut som att den minns allt, men nästan inget av det läses in i nästa session.

| Läses in i nästa session | Sparas – men läses inte in |
|---|---|
| CLAUDE.md och rules | Konversationen – för att återuppta |
| Auto memory (`MEMORY.md`) | `file-history/` – för att backa till en checkpoint |
| Dina egna filer – när CLAUDE.md eller en rule pekar dit | Plans, scratchpad, worktrees – tillfälliga arbetsytor |

| Mapp                                               | Vad den gör                                                                                     |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `projects/<projekt>/<session>.jsonl`               | Hela konversationen – meddelanden, verktygsanrop, resultat. Gör att du kan återuppta.           |
| `projects/.../subagents/`                          | Subagenternas egna konversationer                                                               |
| `projects/.../tool-results/`                       | Stora verktygssvar som sparats separat                                                          |
| `file-history/`                                    | Filer som de såg ut innan Claude ändrade dem – för att backa                                    |
| `plans/`                                           | Planer från plan-läget                                                                          |
| `shell-snapshots/`                                 | Dina alias och skalinställningar, som Bash-verktyget använder. Tas bort när sessionen avslutas. |
| `session-env/`, `tasks/`, `paste-cache/`, `debug/` | Sessionsdata, att-göra-listor, stora inklistringar, debugloggar                                 |


**Utanför `.claude`**
- **Scratchpad** – Claudes kladdyta för mellanresultat, hjälpscript och utkast. Ligger i temp-mappen (`%TEMP%\claude\<projekt>\<session>\scratchpad\`), inte i projektet. Raderas med sessionens konversation – och Windows kan rensa den.
- **Worktrees** – separata arbetskopior av repot på egen branch (se 2.6.3.3 Worktrees). Övergivna worktrees tas bort efter samma tid som konversationerna.

**Hur länge ligger det kvar?**
- Det mesta rensas efter 30 dagar – inställningen `cleanupPeriodDays`.
- Ligger kvar tills du raderar det: `history.jsonl` (alla prompter du skrivit), `stats-cache.json` (det `/usage` visar) och auto memory.
- **Ta inte bort:** `.credentials.json`, `settings.json`, `~/.claude.json`, `plugins/`, `agent-memory/`.
- Städa själv: `claude purge <projekt> --dry-run` visar vad som finns, utan `--dry-run` raderar den.

**Säkerhet**
Allt sparas i klartext – det enda skyddet är filrättigheterna. Läser AI:n din `.env` hamnar nycklarna i konversationsloggen och ligger kvar i 30 dagar (se 4.3 Hemligheter).
- Sänk `cleanupPeriodDays`.
- Neka läsning av `.env` i settings.
