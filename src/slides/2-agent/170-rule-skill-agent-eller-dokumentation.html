Instruktioner

Rule, skill, agent eller dokumentation?

Rule

Vad som måste gälla

Laddas: alltid – eller när den rör matchande filer

T.ex. ”Namnge tester så här”

Gäller alltid → rule

Skill

Hur man gör en uppgift

Laddas: när beskrivningen matchar – eller med /namn

T.ex. ”Skapa en release”

Görs ibland → skill

Agent

Någon som gör jobbet – i egen kontext

Laddas: när description matchar – eller när du ber om den

T.ex. ”Granska min branch”

Egen kontext → agent

Dokumentation

Hur systemet fungerar – och varför

Laddas: när människor eller AI:n behöver förstå

T.ex. ”Så hänger datalagret ihop”

Förklarar varför → docs

Håll filerna korta CLAUDE.md och rules < 200 rader SKILL.md < 500 rader per fil
Fyra sorters instruktioner, fyra frågor. Måste det alltid gälla när den jobbar – rule. Är det något den gör ibland, en uppgift med steg – skill. Behöver jobbet en egen kontext, en färsk blick eller ett eget verktygsset – agent. Skillnaden skill/agent: en skill lägger till instruktioner i samma kontext, en agent jobbar i en egen och lämnar tillbaka ett resultat. Förklarar det hur systemet fungerar och varför – dokumentation, för både människor och AI. Håll filerna korta: Anthropic rekommenderar under 200 rader för CLAUDE.md, som laddas i varje session. Rules utan paths laddas på samma sätt, så samma gräns är rimlig där, och under 500 för SKILL.md, som bara laddas vid behov. Det gäller per fil. Långa filer äter kontext och den följer instruktionerna sämre. Mitt eget max är 250 rader – det var rekommendationen när jag satte upp det. Saker ändras, häng med. Se anteckningarna i 2.6.5 Håll isär.
