Jag var på en föreläsning förra hösten på Queenslab där Tore Nestenius pratade om Vad en agent är och jag minns den aha upplevelsen jag hade när det stod klart för mig att det bara är en loop.

**Modellen minns ingenting**
Modellen har inget minne mellan anropen. Varje gång den ska svara skickar ditt harness med allt den behöver veta:

- **Systemprompten** – instruktioner för hur agenten ska bete sig
- **Verktygen** – en beskrivning av vad den kan använda: läsa filer, redigera, köra kommandon, MCP-servrar
- **Hela historiken** – allt ni sagt, alla filer den läst, alla resultat från verktyg
- **Din nya fråga**

Det är det som gör att det känns som ett samtal. Det är inte modellen som minns – det är harness som påminner den, varje gång.

**Loopen**
```
Du skriver
   ↓
Harness skickar: systemprompt + verktyg + hela historiken
   ↓
Modellen svarar ──→ bara text? ──→ klart, du ser svaret
   ↓
"Jag vill använda Read på fil X"
   ↓
Harness kör verktyget        ← hooks körs här, före och efter
   ↓
Resultatet läggs till i historiken ──→ tillbaka till modellen
```

Som kod är det förvånansvärt lite:
```
historik = [din fråga]
while True:
    svar = modell(systemprompt, verktyg, historik)
    historik.append(svar)
    if not svar.vill_använda_verktyg:
        break
    resultat = kör_verktyg(svar)
    historik.append(resultat)
```

**Modellen kör aldrig något själv**
Den *ber* om att få använda ett verktyg – det är harness som kör det. Därför kan settings och hooks stoppa den: de sitter i loopen, utanför modellen. Ett förbjudet kommando körs inte, hur gärna modellen än vill.
